# Куб / Граф

Интерактивный кубик Рубика 3×3×3 и синхронная визуализация 54 наклеек на девяти пересекающихся окружностях.

Сайт: https://rubik-graph-lab-alikt.akishevakzhan.chatgpt.site/

## Возможности

- Повороты внешних и средних слоёв свайпом мышью или пальцем.
- Перетаскивание фона или Shift + перетаскивание для изменения ракурса.
- Синхронная анимация точек на графе слоёв.
- Перемешивание, отмена, сброс, автоматическая демонстрация с паузой.
- Клавиши U, D, L, R, F, B; M, E, S для средних слоёв. Shift — обратный ход.

## Локальный запуск

Не требует сборки или установки npm-пакетов. Нужен статический HTTP-сервер, например Python 3:

```sh
python -m http.server 4173 --directory dist
```

Откройте http://localhost:4173/.

## Структура

- `dist/index.html`, `dist/style.css` — интерфейс и стили.
- `dist/model.js` — модель кубика и перестановки наклеек.
- `dist/ring-graph.js` — геометрия окружностей и траектории точек.
- `dist/app.js` — отрисовка, жесты и синхронизация представлений.
- `.openai/hosting.json` — настройки существующего сайта Sites; не содержит токенов.

Граф показывает наклейки и слои одного кубика, а не пространство всех его состояний. Управление работает независимо от доступности экспериментального WebMCP API. Шрифт загружается из Google Fonts; при недоступности используется системный.
